# Responsive Repair Plan

Scope: targeted repair of the existing portfolio; approved narrative copy and project structure remain unchanged.

1. Replace conflicting global layout rules with one responsive token and breakpoint system. This removes stale fixed/minimum desktop dimensions that survive at small viewports.
2. Replace the desktop-only global header with an accessible client-side mobile menu that traps neither layout width nor background scrolling.
3. Rebalance type scale, line-height, and section rhythm across the homepage and technical pages without editing approved copy.
4. Preserve the seven-layer artwork and contained inspector. Refine its desktop grid, sticky boundary behavior, and narrow-screen sheet rules.
5. Retain real local visuals already present (portrait and architecture artwork); keep project slots restrained and inventory missing genuine captures rather than fabricating replacements.
6. Validate at the directive’s target widths, run copy/type/build checks, and record visual evidence and any remaining limitations.
